# Shlok Ghadekar, portfolio

A single-page Next.js site. All project content lives in `lib/projects.ts`, and contact and resume links live in `lib/links.ts`, so updating the site usually means editing one of those two files.

```bash
npm install
npm run dev
```

Design notes: cool grey paper with blue-black ink, Literata for prose and Hanken Grotesk for interface text. Yellow marker highlights measured results. Red-pen notes record what didn't work. The only animation that plays on its own is the hero highlights drawing in on load; the project rows animate only when opened.
