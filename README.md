# Shlok Ghadekar, portfolio

A single-page Next.js site. All project content lives in `lib/projects.ts`, and contact and resume links live in `lib/links.ts`, so updating the site usually means editing one of those two files.

```bash
npm install
npm run dev
```

Design notes: cool grey paper with blue-black ink, Literata for prose and Hanken Grotesk for interface text. Yellow marker highlights measured results; red-pen notes record what didn't work. The AgentHQ demo video in `public/work/` plays muted in the hero (paused for visitors who prefer reduced motion). Project figures are defined as data in `lib/projects.ts`: charts, screenshots or a demo video.
